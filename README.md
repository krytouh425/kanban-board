# Kanban Board

Персональная Kanban доска для управления задачами.
Построена на Python + Flask с drag & drop интерфейсом.

## Технологии
- Python 3 + Flask — бэкенд
- HTML/CSS/JS — фронтенд
- JSON — хранение данных

## Запуск
pip install flask
python app.py

## Возможности
- Три колонки: Нужно сделать / В процессе / Готово
- Drag & drop карточек между колонками
- Приоритеты карточек (высокий / обычный / низкий)
- Добавление и удаление карточек
- Описание к каждой карточке
